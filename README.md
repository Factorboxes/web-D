# Factorboxes — โปรแกรมคำนวณต้นทุนกล่อง

ชุดไฟล์เว็บไซต์พร้อมอัปขึ้น GitHub ใช้ HTML, CSS และ JavaScript โดยไม่ต้องติดตั้งแพ็กเกจ ไม่ต้อง Build และไม่ต้องตั้งค่า API key

## อัปไฟล์ขึ้น GitHub

1. แตกไฟล์ `Factorboxes-GitHub-Ready.zip` ก่อน
2. สร้าง Repository สำหรับโปรแกรมนี้ เช่น `factorboxes-calculator`
3. เปิด Repository แล้วเลือก **Add file → Upload files** ถ้าเป็น Repository ว่าง ให้กดลิงก์ **uploading an existing file**
4. อัปโหลดไฟล์ทั้งหมดที่แตกออกมา โดยให้ `index.html` อยู่หน้าแรกของ Repository ระดับเดียวกับ `app.js`, `math.mjs` และ `styles.css`
5. ใส่ข้อความบันทึก เช่น `Add box cost calculator` แล้วบันทึกการเปลี่ยนแปลงลงใน Branch หลัก

อัปโหลดไฟล์ที่อยู่ภายใน ZIP ไม่ใช่อัปไฟล์ ZIP ทั้งก้อน วิธีอัปโหลดเพิ่มเติมดูได้จาก [คู่มือ GitHub](https://docs.github.com/en/repositories/working-with-files/managing-files/adding-a-file-to-a-repository)

หากเคยอัปเวอร์ชันก่อนแล้ว ให้อัปโหลดไฟล์ชุดใหม่นี้ทับไฟล์ชื่อเดียวกันในตำแหน่งเดิม แล้วโหลดหน้าเว็บไซต์ใหม่หลังเผยแพร่เสร็จ

## เปิดใช้เป็นเว็บไซต์ด้วย GitHub Pages

เมื่อ Repository เปิดใช้ GitHub Pages ได้ ให้ตั้งค่าดังนี้:

1. ไปที่ **Settings → Pages**
2. ใน **Build and deployment → Source** เลือก **Deploy from a branch**
3. เลือก Branch ที่อัปไฟล์ไว้ เช่น **main** และโฟลเดอร์ **/(root)** แล้วกด **Save**
4. เมื่อเผยแพร่เสร็จ เปิด URL ที่แสดงในหน้า Pages เพื่อใช้งานโปรแกรม

ดูรายละเอียดและเงื่อนไขบัญชีได้จาก [คู่มือตั้งค่า GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## โปรแกรมเวอร์ชันนี้

- คำนวณต้นทุนกระดาษจากขนาดกล่องหรือขนาดแผ่น
- ขนาดแผ่นเลือกได้ทั้งเซนติเมตร นิ้ว เมตร และฟุต เปลี่ยนหน่วยแล้วแปลงตัวเลขให้อัตโนมัติ
- กรอกราคาซื้อกระดาษแต่ละช่วงเวลาได้ เป็นบาทต่อตารางฟุตหรือบาทต่อตารางเมตร
- ส่วนที่ 3 มี 6 รายการหลัก: ราคาต้นทุน, ฐานราคาต้นทุน, VAT, ส่วนลด, ค่าธรรมเนียมการขาย และกำไรที่ต้องการ โดยเลือกวิธีคิดเปอร์เซ็นต์กำไรได้
- เริ่มต้นด้วย **บวกกำไรจากต้นทุน** ตามวิธีใน Excel เดิม เช่น ต้นทุน 100 บาท + กำไร 25% = ราคาขาย 125 บาท เมื่อไม่มีส่วนลด ค่าธรรมเนียม และ VAT
- ยังเลือก **กำไรเป็นเปอร์เซ็นต์ของยอดขาย** ได้ เช่น ต้นทุน 100 บาท กำไร 25% ของยอดขาย = ราคาขาย 133.34 บาท เมื่อไม่มีส่วนลด ค่าธรรมเนียม และ VAT และปัดขึ้นเป็นสตางค์
- แสดงราคาที่รวมต้นทุนและกำไรทันทีในส่วนที่ 3 พร้อมราคาที่รวม VAT ต้นทุนสินค้า ค่าธรรมเนียม และกำไรต่อกล่อง
- แถบด้านล่างบนมือถือแสดงราคาต้นทุนรวมกำไรก่อน VAT และกดไปยังส่วนต้นทุนและกำไรได้
- ใช้งานบนมือถือและคอมพิวเตอร์ คำนวณทันทีเมื่อแก้ตัวเลข

**ราคาต้นทุนในส่วนที่ 3** คือยอดต้นทุนรวมต่อกล่องที่กรอกเอง โปรแกรมใช้ยอดนี้แทนต้นทุนกระดาษในการตั้งราคาขาย จึงไม่บวกต้นทุนกระดาษซ้ำ หากเว้นว่างจะใช้เฉพาะต้นทุนกระดาษที่คำนวณจากส่วนที่ 1–2

กำไรที่แสดงเป็นประมาณการเมื่อขายได้ตามราคาที่โปรแกรมคำนวณ โดยคิดส่วนลดและค่าธรรมเนียมก่อน VAT ค่าตัวอย่าง เช่น ราคากระดาษ 0.68 บาท/ตารางฟุต และ VAT 7% แก้ไขได้ตามงาน ข้อมูลที่กรอกจะกลับเป็นค่าตัวอย่างเมื่อโหลดหน้าใหม่

ราคาตั้งขายเผื่อส่วนลดและค่าธรรมเนียมเพื่อให้ได้กำไรตามที่กำหนด และปัดขึ้นเป็นสตางค์ ค่าธรรมเนียมคิดจากยอดขายหลังส่วนลดก่อน VAT ราคาต่อกล่องที่รวม VAT และรายละเอียดต้นทุนแสดงได้สูงสุด 4 ตำแหน่ง ส่วนยอดรวมคิดจากค่าจริงก่อนปัดแสดงผล

ตัวอย่างที่ตรวจสอบแล้ว: ต้นทุน 14.12 บาท บวกกำไรจากต้นทุน 25% ไม่มีส่วนลดและค่าธรรมเนียม ได้ราคาก่อน VAT **17.65 บาท** และกำไร **3.53 บาทต่อกล่อง**

## ทดลองบนคอมพิวเตอร์

หากติดตั้ง Python 3 ไว้ ให้เปิด Terminal ในโฟลเดอร์ที่มี `index.html` แล้วรัน:

```sh
python3 -m http.server 8080
```

บน Windows ใช้ `py -m http.server 8080` จากนั้นเปิด `http://localhost:8080` ในเบราว์เซอร์ โปรแกรมใช้ JavaScript modules จึงควรเปิดผ่านเว็บเซิร์ฟเวอร์ ไม่ใช่ดับเบิลคลิกไฟล์ HTML
